# Folio 控制台 UI 重构

基线：main / 00e4f15；特性分支 feat/folio-ui-redesign。
模式：Redesign · Preserve。对象为团队成员和管理员使用的 Folio 工作台，电脑近距离工作、手机查看与反馈；语气安静、清晰，首屏优先展示作品和待处理反馈。

## Design Read

布局变化 4、动效 2、信息密度 7、素材依赖 2、品牌一致性 9。稳定网格和任务优先的分栏提高扫读效率；只使用悬停、焦点和加载反馈；不增加展示性动画。所有数量来自 API 返回的数据。

## 视觉系统

沿用 eat 的 shadcn Neutral 令牌：background/card 白、primary/foreground 近黑、muted 浅灰、border 中灰；success 仅表示发布/解决状态，destructive 仅表示删除和错误。保留平台原生中文字体及等宽 URL，不引入外部字体。4/8px 间距基准，主要分区间距 24–32px；面板 12px、控件 8px 圆角，浮层沿用现有阴影，日常内容用分隔线。状态反馈 150ms，尊重 reduced-motion。

列表承担发现与进入作品的角色，展示真实发布状态、权限与更新时间；详情头承担识别作品、打开和发布；评论区承担反馈处理，使用单列讨论流与底部输入框；发布记录承担历史比较与恢复，使用语义化表格；设置按基本信息、访问权限和路由分组，删除独立。创建/发布浮层围绕单一任务。嵌入评论保留固定底部新评论入口和独立滚动。

## 列表密度调整（2026-10-17）

模式：Redesign · Preserve；面向在电脑上查找、打开和管理作品的团队成员。布局变化 3、动效 2、信息密度 8、素材依赖 1、品牌一致性 9。沿用 Neutral 颜色、原生字体、Folio 名称和图标库；状态绿只表示已发布。分区间距 16px，卡片内边距 16px、间距 8–12px、圆角 10px，控件圆角 6–8px，悬停和焦点反馈 150ms，无新增展示动画或阴影。

移除列表介绍条、每张卡片的重复大图标及空说明占位；列表内容上限扩至 1600px，自适应排列紧凑卡片，并提供可记忆的行视图。名称、标识和说明负责识别，状态、权限和更新时间负责判断，打开、复制和管理入口集中在底部。卡片空白处通过标题链接进入详情，独立操作保留各自的链接/按钮语义；草稿只提供有效的详情或发布入口。搜索可清空，空结果可重置筛选，支持按更新、创建时间或名称排序。

保留现有路由、创建表单、访问控制、API、权限和详情页布局；宽度调整仅用于 `/folios`。风险集中在卡片覆盖链接与独立操作的点击层级，使用相对定位及独立焦点状态隔离。

## 评论区视觉迭代

平台和网站评论采用相同的轻量讨论语言，参考 web-design-engineer 的 Linear 配方中的精确间距、弱分隔与克制反馈，适配 eat 的浅色工作台。头像、作者和正文左对齐；回复通过缩进与细线表达层级；操作以行内图标和文字呈现，上下文按需展开。筛选使用下划线标签，输入框整合 @、页面或标注工具、发送按钮，内容随输入自动增高。仅计数、头像和聚焦状态少量使用 #5e6ad2；正文保持中性灰，解决状态保留语义绿。网站面板使用轻阴影与 14px 圆角。

网站面板进一步采用讨论组交互：默认展示未解决讨论，底部独立折叠已解决；点选时展开回复与组内编辑器，并定位页面标注。同一时间只展开一组回复，新评论入口保持轻量收起；选中态仅使用浅灰背景和细边框。管理操作收进 `⋯`，触屏常显且保留 44px 点击范围。位置选择收成单一菜单，@ 候选使用可自动避让边缘的浮层。右下角白底灰色评论按钮沿用原样。控制台仍保留原有状态筛选和行内操作。
