# RAM 个人身份备注保留归属与完整用户 ID，超长邮箱截断显示

RAM 的 [CreateUser](https://help.aliyun.com/en/ram/developer-reference/api-ram-2015-05-01-createuser) 和 UpdateUser 将备注限制为 128 个字符。EAT 用户邮箱可能长于剩余空间，所以“备注含完整 EAT 用户 ID 和邮箱”无法对任意邮箱同时成立。

我们决定保留完整 EAT 用户 UUID 和 EAT 归属标记，只在 RAM 备注中把超出空间的邮箱截断，并追加单字符省略号 `…`。按 Unicode 字符截断，避免切断字符；长度不超过限制时完整保留邮箱。EAT 数据库中的邮箱始终保留完整值。用户已确认这条例外。

归属标记包含本地个人身份 UUID 的紧凑随机标识，结合持久化的云端 UserId 判断来源。邮箱属于展示资料，不参与归属判断；用户改名或改邮箱后，下次执行授权会更新 RAM 显示名和备注。

## Considered Options

- **因邮箱过长拒绝授权**：邮箱长度并不改变用户是否有权获得权限点，会阻止正常授权。
- **缩短 EAT 用户 ID 或归属标记**：让人工识别和来源验证变弱，不采用。
- **修改 EAT 邮箱**：会损失平台资料，不采用。

## Consequences

- RAM 控制台里长邮箱可能只显示前缀和省略号，完整邮箱从 EAT 查阅。
- 名称相同但来源标记或已保存的云端 UserId 不符时仍拒绝接管；截断不影响归属验证。
- RAM 内存测试实现也执行备注、显示名的 128 字符限制，防止测试掩盖真实云约束。
