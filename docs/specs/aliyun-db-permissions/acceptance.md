## 仍适用的限制与使用边界

| 范围 | 限制与验收边界 |
| --- | --- |
| 数据库支持与权限粒度 | 本期只支持 PostgreSQL 数据库权限，真实行为以本地 PostgreSQL 16 验证；未验证其他版本的完整权限行为。MySQL 不支持开放或外部登记。授权按 schema，不提供 DDL、TRUNCATE、库所有权或逐表勾选。 |
| 数据库管理能力 | 管理身份需具备相应 CREATEROLE、对象 owner 的 SET／授予能力。其他角色新建对象可能需要重新应用授权；缺权限时执行失败并返回 DBA SQL。外部库的 PUBLIC 和继承权限只报告，由 DBA 收紧。 |
| 删除与 PG16 多 grantor | 角色仍有对象所有权、无法撤销 foreign grantor 关系或存在依赖转授时，停止或回滚并报告精确 DBA SQL；不会 DROP OWNED 或 CASCADE。成员漂移核对只读，仅显式修复更改状态。 |
| 个人凭证与 owner | 个人凭证仅供本人临时使用。停用只切断个人凭证，分配出去的 owner 账号与业务连接保留；Owner 转交和 owner 密码轮换不在本期。数据库个人角色／密码按实例复用，重置影响该实例其他授权库。 |
| 阿里云配额与 Key | 真实账号当时为每人最多 2 把 Key、10 条自定义策略；策略配额可调，OSS 聚合策略占用名额。此次真实实测不代表其他账号的当前配额。新 Key 的传播等待期限持久化；默认等待 45 秒，可配置。 |
| 接入与共享身份 | 接入暂停阻止新申请、批准、直接授予及新 Key 创建；已有 Key 仍可读取，撤销和安全停用照常执行。OSS 与阿里云共用身份和 Key，重置会同时影响两者。非受管绑定可能阻止纯阿里云身份清理，需人工处理。 |
| OSS 迁移 | 生产迁移没有执行，旧路径代码仍保留。迁移需管理员显式执行／重试；running／partial 持久阻止普通 OSS 写，安全停用仍可执行。内存云端测试不等同于生产批量迁移验证。 |
| 测试覆盖 | 多真实云账号联调不在本次范围，多账号逻辑使用 TestRamCloud；普通 Server 测试的云调用使用 RAM／OSS 替身，通知及飞书场景也使用测试传输。UI 覆盖 Chromium 桌面及手机视口，未覆盖真实手机硬件或其他浏览器。真实云脚本需显式 opt-in，不进默认测试。 |
| 产品范围 | 不新增个人权限 MCP 工具，仅扩展统一申请查询的类型枚举；审批、管理、直接授予他人和修复等操作在控制台提供。授权到期、自动修复及跨模块统一“我的权限”页不在本期。 |
